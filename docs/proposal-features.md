# 제안서 기능: 해역 지표 지도, 보기 수준, 대체생산 우선 노출

상태: **팀 시범 규칙 · 외부 검증 전** (2026-09-25). 규칙 원본은 `config/display-rules.json`이고, 사이트가 읽는 사본 `dist/display-rules.json`은 바이트 단위로 같아야 합니다(`verification/uicheck.mjs`가 확인).
표시 규칙은 사이트에서 무엇을 먼저 보여 줄지만 정합니다. 지표 값은 바꾸지 않고, 규칙에 해당하지 않는 종의 등급을 낮추지도 않습니다. 지표 값은 `scripts/build_verified_indices.py`가 만든 `dist/assessments.json`에서만 옵니다.

## 규칙과 기준값

| 기능 | 규칙·기준값 | 제약 | 제안서 대응 | 상태 |
|---|---|---|---|---|
| D-1 해역 지표 보기 | 기본은 꺼짐. 가로축은 BBVI(기본), 식량 전용(MFPI), 생리활성 전용(MBPI) 중 선택하고 세로축은 MCUI. 셀 값은 그 셀에 기록된 종 가운데 최댓값이고 팝업에 평균도 표시. 3단계 구간: <33.3 / 33.3–66.7 / ≥66.7 | 종 단위 지표를 셀에 요약한 것이지 해역 등급이 아님. 전체 분포가 아니고, 값이 산출된 종이 적음. 산출된 종이 없는 셀은 빗금으로 표시(0점 아님). 4° 셀은 1°로 나누지 않음 | 해역별 활용·보전 지도 | 새 기능 |
| D-2 보기 수준 | 시민: 세부 내용 접힘. 연구자: 근거 패널 펼침 + 정밀 좌표 이용 신청 안내. 기관: 연구자 보기 + 셀 CSV + 기관 확인 항목 강조. URL 해시 `l=` | 모든 수준에서 지표 값, 공개 셀, 경고 문구가 같음(uicheck로 확인). 로그인이나 승인 기능은 없고 사이트는 개인정보를 저장하거나 전송하지 않음 | 이용자 유형별 공개 수준 | 새 기능 |
| D-3 대체생산 우선 (기본) | `BBVI ≥ 60` **그리고** `MCUI ≥ 80`이면 대체생산·양식 카드를 상세 패널 맨 위에 표시 | 현재 BBVI가 산출된 종이 없어 해당 종 0개 | 제안서 p.4 | 제안서 기본 규칙 |
| D-3 보전 우선 검토 (추가) | `MCUI ≥ 80`이면 같은 카드 표시 + 지도 셀 문구 "이 종은 보전 우선 검토 대상 · 채집 위치 안내가 아님" | 채집 권장이 아님. 대체생산 근거가 없으면 "대체생산 근거 미수집"으로 표시 | 제안서 취지 | **새로 추가한 시범 규칙** |

### 추가 규칙을 둔 이유

- 이전: 기본 규칙(BBVI ≥ 60 그리고 MCUI ≥ 80) 하나뿐.
- 이후: 기본 규칙에 "MCUI ≥ 80만으로 카드 표시" 규칙을 더함.
- 이유: 지금은 BBVI가 산출된 종이 없어 기본 규칙에 해당하는 종도 없습니다. 보전 필요성이 높은 종(현재 해삼, MCUI 80.0)은 좌표보다 대체생산 정보를 먼저 보여 준다는 제안서 취지를 따르려고 규칙을 추가했습니다. 기존 규칙이나 기준값을 완화한 것은 아닙니다.

### 대체생산 근거 (해삼)

- 출처: FAO Fisheries Technical Paper 463 (2004), Wang & Cheng, pp. 277–286.
- 내용: 중국 다롄 지역의 종묘 생산과 양식·바다목장 사례입니다.
- 제약: 한국 해역 자료가 아니고, 어미는 자연산을 씁니다. 생산량이나 비용을 추정한 자료도 아닙니다. 자세한 내용은 `research/verified-indices/nutrition-audit.md`에 있습니다.
- 지표 값은 바뀌지 않았습니다. 국립수산과학원(NIFS) 자료는 아직 검토하지 않았습니다.

## 정밀 좌표 이용 신청

- 연구자·기관 수준에서만 보입니다.
- 받는 주소 `coordinate_request.mailto`는 **아직 정하지 않았습니다(null)**. null이면 신청 링크 없이 안내 문구만 표시합니다. 주소가 정해지면 config와 dist 사본을 함께 수정합니다.
- 신청 항목: 목적, 기관, 사용 범위, 기간, 재배포 여부.
- 검토 기준: 민감종 여부, 원자료 제공처 이용조건.
- `dist/`에는 소수 셋째 자리 이상의 위경도가 없습니다. uicheck가 `countries.json` 기본 지도와 `vendor/`를 빼고 검사합니다.
