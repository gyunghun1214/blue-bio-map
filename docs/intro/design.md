# 메인 지도 로딩·입장 화면 설계

기준: "처음 온 사람이 '바다 생물의 가치를 근거로 보는 지도'에 들어간다는 기대를 갖고, 기다림 없이 자연스럽게 지도로 넘어가는가?"
참고: OceanX 2025 첫 화면 두 장(로딩 → 입장). 레이아웃과 분위기만 참고하고 로고·사진·지구본 영상·폰트·협력사 로고는 쓰지 않는다.
디자인 스킬: `frontend-design`(계획 → 브리프 대조 → 구현 → 스크린샷 자기 비평 순서를 따름).

## 토큰

| 이름 | 값 | 쓰임 |
|---|---|---|
| sea | `#030d1a` | 바탕, 로딩 화면 |
| deep | `#06213a` | 구의 바다면 |
| ink | `#eaf3f7` | 제목·본문 |
| ink2 | `#a9c0cc` | 보조 글 |
| teal | `#5ee3d0` | 진행 호, 공개 격자, 라벨 사각형 |
| warm | `#f08a4b` | 입장 버튼의 점 하나에만 |

탐험 페이지(`expedition.css`) 토큰과 같은 값이라 두 화면이 한 사이트로 읽힌다. 서체는 기존 Pretendard 하나(굵기 700 제목, 400–600 본문). 새 폰트·외부 CDN 없음.

## 배치

```
[○ 움직임 줄이기]            [물결 마크  Blue-bio Value Map]
                       ╭──────── 구(바다 렌즈) ────────╮
      ■ 한반도 주변 바다 · 30종의 근거
      바다의 가능성,
            근거에서부터.
                    ( 지도 들어가기   ● )
                          Enter ↵
                    함께 읽는 공개 자료
          WoRMS  OBIS  GBIF  IUCN 적색목록  ChEMBL  식품성분표
                       ╰─────────────────────────────╯
[소개 3–4줄]        © 2026 alt F4 · 연구 프로토타입 · 바다 탐험으로 시작     [링크 공유 ↗]
```

- 제목은 왼쪽 정렬 두 줄, 둘째 줄을 오른쪽으로 들여 참고 화면의 엇갈린 리듬을 살린다. 문구는 지도 첫 화면 제목과 같은 "바다의 가능성, 근거에서부터."(사이트 목소리를 한 가지로 유지).
- 버튼·자료 줄은 가운데, 소개는 왼쪽 아래, 공유는 오른쪽 아래.
- 모바일(390px): 제목 두 줄 유지(약 12vw), 소개는 버튼 아래로 쌓고, 자료 줄은 줄바꿈 허용. 구는 화면 높이에 맞춰 크게 두고 잘려도 된다.

## 가장 기억에 남을 한 가지: 바다 렌즈

사진 지구본 대신, 한반도 주변 바다를 국제우주정거장 고도쯤에서 내려다본 **수직 원근 투영 구**를 Canvas 2D로 그린다.

- 해안선: 앱이 이미 불러오는 `countries.json`(Natural Earth 1:10m, public domain). 같은 파일을 두 번 받지 않도록 app.js가 준비 이벤트로 넘겨 준다.
- 경위선 2°·10° 간격, 구 가장자리로 갈수록 어두워지는 림과 바깥 대기 빛.
- 정보가 있는 구조만 얹는다: 지도 시험 범위(124–132°E · 33–38.7°N) 점선 틀, 앱이 실제로 불러온 **공개 집계 격자(1°·4°)** 칸을 은은한 청록으로. 구 아래에 "청록 칸: 관측 기록이 있는 공개 집계 격자(1°·4°)"를 작게 밝힌다. 새 좌표·위치 정보는 만들지 않는다.
- 움직임은 이것 하나: 아주 느린 흔들림(경도 ±3°, 위도 ±1°). `prefers-reduced-motion` 또는 "움직임 줄이기"면 멈춘다.
- Three.js(약 690 KB)는 쓰지 않는다. 메인 페이지 첫 로딩을 무겁게 하고, 이 그래픽은 2D로 충분하다.

## 로딩 화면

- 가운데 물결 마크 + 워드마크, 그 아래 단계 문구. 바깥에 점선 원 궤도와 그 위를 도는 청록 빛 점.
- 궤도 위 실선 호가 **실제 준비 단계**만큼 찬다: 1/3 페이지 준비 → 2/3 지도 준비(`countries.json`+Leaflet) → 3/3 종 자료 준비(`loadCollection` 끝). 가짜 퍼센트·가짜 타이머 없음.
- 최소 표시 0.6초(깜빡임 방지), 최대 7초. 7초가 지나면 입장 화면을 열고 "자료를 계속 불러오는 중입니다. 먼저 들어가도 됩니다"를 보인다.
- 전환: 점선 궤도가 커지며 구로 이어지는 한 번의 연출.

## 입장 규칙

- 입장: 버튼 클릭, 버튼의 Enter/Space, 입장 화면 어디서든 Enter(다른 버튼·링크에 포커스가 있으면 그 버튼 동작이 우선).
- 입장 후 포커스: 마우스 환경은 검색창, 터치 환경은 `<main>`(모바일 키보드가 갑자기 뜨지 않게).
- 건너뛰기: 앱 해시(`s v t b m p u`)가 있으면 표시 안 함, 같은 탭에서 이미 입장했으면 표시 안 함(`sessionStorage`), JS가 없거나 `intro.js`가 실패하면 표시 안 함(기본 숨김, JS가 `<html class="gate-on">`을 걸 때만 표시).
- 입장 화면이 떠 있는 동안 뒤 화면과 챗봇은 `inert`.

## 브리프 대조에서 바꾼 것

- 참고 화면의 영문 모노 대문자 라벨(`OCEANX 2025 IN REVIEW`)과 영문 버튼은 그대로 옮기지 않았다. 이 사이트는 한국어 사용자용이라 라벨은 한국어 한 줄로, 버튼은 "지도 들어가기"로 한다(스킬 지침: 장식용 대문자 라벨은 생성형 디자인의 흔한 흔적).
- 협력사 로고 줄은 "함께 읽는 공개 자료" 이름 줄로 바꿨다. 로고 이미지는 쓰지 않는다. 이름은 README·방법 탭에 실제로 나오는 자료만.
- 오디오 자리는 소리 대신 "움직임 줄이기"로 바꿨다.
- 숫자(30종 등)는 손으로 적지 않고 로딩이 끝난 뒤 `운영 발행 N종 · 조사 후보 M종`을 앱 값에서 채운다. 아직 모르면 숫자 없이 둔다.
