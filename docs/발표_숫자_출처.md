# 발표 숫자 출처 표 (발표 v4, 2026-10-21)

발표(v4, 33장)에 나오는 바깥 숫자와 그 출처를 한 곳에 모았다. 발표 2·4·6장 숫자 옆 출처와 33장 '통계·제도 인용' 목록은 이 표와 같아야 한다.

- 행은 심사단 v4 평가서 3절 '숫자 대조'의 11행에서 시작했고, 6장의 제도 날짜를 더했다.
- '원문 확인'은 2026-10-21 클라우드에서 실제로 연 자료를 기준으로 적었다.
  - **1차**: 보고서나 논문 원문, 또는 저장소의 원자료에서 값을 직접 확인했다.
  - **2차**: 원문을 다룬 기사나 요약에서만 확인했다.
  - **원문 확인 못 함**: 열지 못했거나 값을 찾지 못했다.
- 이 문서는 화면 문구가 아니다. 그래서 확인하지 못한 것도 그대로 적는다.

## 1. 우리 원자료로 계산한 숫자 (KOSIS)

출처는 모두 KOSIS「어업생산동향조사」 품종별 생산량(통계표 DT_1EW0004, https://kosis.kr/statHtml/statHtml.do?orgId=101&tblId=DT_1EW0004)이다. 2026-10-14에 내려받은 원자료가 저장소에 있다.

- `data/raw/kosis_DT_1EW0004_national_2015_2025.csv`
- `data/raw/kosis_DT_1EW0004_mariculture_items_2015_2025.csv`

이 값들은 `dist/assessments.json`의 `stock_decline`에 들어가 사이트에 보인다. 클라우드에서는 KOSIS 화면을 다시 열지 못했다. 그래서 '1차'는 저장소 원자료와 같다는 뜻이다.

## 4. 발표에서 맞출 곳

- **2장**: 23,491톤 · 94톤 옆에 'KOSIS 어업생산동향조사(2024년)'를 적는다.
- **4장**: 64.5% → 62.4% 아래 단서에서 '2,570개 자원'을 빼거나, 원문 쪽 번호를 확인한 뒤에만 남긴다. 제안서의 '직전 보고서 64.5%' 표현은 '2021년 64.5%(2026년판 값)'로 맞춘다.
- **18장**: '채취량 −90.2%'를 '어획량 −90.2% (KOSIS)'로 맞춘다.
- **28장**: 아래에 '자료 출처: 33장'을 적는다.
- **33장**: '통계·제도 인용'에 KOSIS 어업생산동향조사(DT_1EW0004)를 더한다. 나머지 항목은 이 표의 출처 이름과 판을 같게 쓴다.
