# OceanX 2025 레퍼런스 관찰 (2026-10-08)

관찰 대상: https://2025.oceanx.org/ (데스크톱 1280×720, 모바일 390×844 에뮬레이션). 데스크톱 앱 내장 브라우저로 직접 조작했다. 캡처는 저장소에 두지 않았다. 코드·에셋은 가져오지 않고 원리만 적는다.

확인 방법: **직접** = 브라우저에서 보고 조작함 · **자료** = 제작사 인터뷰(commarts.com/webpicks/oceanx-2025) · **미확인** = 보지 못함.

| 특징 | 확인 방법 | 내 플랫폼 적용 |
|---|---|---|
| 렌더링: 화면 전체를 덮는 WebGL 캔버스 1개, 문서 높이가 화면 높이와 같다(스크롤바 없음). 휠 입력이 가상 진행값을 움직인다 | 직접(개발자 도구로 canvas·`body.scrollHeight` 확인) / 자료(three.js + HTML UI, 콘텐츠는 JSON 1개) | Three.js 캔버스 1개 + HTML 오버레이. 탐사 지점은 `expedition-stops.json` 하나에서 읽는다 |

## 구현 방향 요약

1. 바다·배·항적이 화면의 주인공이고, 항해 중 글자는 최소로 둔다.
2. Three.js 캔버스 1개 위에 HTML 오버레이(카드·패널·진행선)를 얹는다. 빌드 도구 없이 `dist/vendor/`에 고정 버전.
3. 모든 화면은 상태 하나(`stop·phase·reveal·detailOpen`)에서 그리고, 입력은 목표 지점만 바꾼다.
4. 도착하면 해역 → 생물 → 핵심 가치 순서로 단계 등장, '자세히 보기'에서 근거 전체.
5. 상세는 패널 안에서만 스크롤, 닫으면 그 자리에서 이어서 항해.
6. 지점 목록으로 바로 이동, 상단 진행선으로 위치 감각을 준다.
7. 배는 항상 뱃머리 방향으로 나아간다.
8. 색: 짙은 네이비 + 흰 글자 + 청록 라벨 + 따뜻한 주황 포인트 소량.
9. 모바일은 하단 시트, 모션 감소·WebGL 실패 때는 같은 데이터의 카드 목록.
