# Evidence-based pilot indices: design decision (2026-09-24 UTC)

This decision precedes the code in this branch. The proposal pp. 3–4 defines the **components and separation**, not a calibrated formula. MFPI uses food composition, edible yield and culture feasibility; MBPI connects origin organism, identified molecule, comparable quantitative experiment and original paper; MCUI retains IUCN risk separately, using occurrence data only after bias control; BBVI combines the first two and is plotted against MCUI. Evidence sufficiency is a separate dimension.
