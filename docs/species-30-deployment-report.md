2단계 (#49)
- NIBR 국가생물적색자료집 2024의 국가 평가 8종(모두 LC)을 IUCN 설명 옆에 "국가 평가(한국 범위)"라는 사실 정보로 표시한다. MCUI 점수에는 넣지 않는다. 테스트가 이 조건을 고정한다.
- 미역: MEXT 09039 폐기율 35%를 근거로 가식부 0.65 민감도(MFPI 38.7)를 추가했다. 점수 42.2는 유지한다.

- MBPI "미발견"은 검색 범위를 표시한다. 조사한 곳은 Wikidata/LOTUS와 ChEMBL 37이다. PubChem·CMNPD·문헌은 아직 조사하지 않았다.
- 맛조개 국명 메모를 추가했다. 국가 게재명은 가리맛조개이고, *Solen strictus*와 다른 종이다.
- 캐시 버전: app.js 0.3.18(c3dd0e9) → 0.3.24(#48) → 0.3.25(#49). style.css 0.3.8 → 0.3.9와 live-data.js 0.2.13 → 0.2.14는 #48에서 올렸다.

- 2단계만 되돌리기: main에 `git revert -m 1 60b04b5` 커밋을 올린다.
- 1단계까지 되돌리기: 그다음에 `git revert -m 1 0d15df6` 커밋을 올린다. 두 번 되돌리면 `c3dd0e9`와 같은 공개 파일이 된다.
