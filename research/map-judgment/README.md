## 화면 규칙

- 범례는 운영/시연 모두에서 항상 보인다. 셀 색은 **선택한 종**을 구분하며 생물량·활용성·위기 정도를 나타내지 않는다. 운영 셀은 점선 테두리, 별도 OBIS 시연 격자는 시연이라고 표기한다. 실제 해역별 판단 승인 수는 **0곳**이고, 출현 셀을 클릭해도 활용·보전 유형이나 점수를 표시하지 않는다.
- 운영 셀 팝업은 `year_start/year_end`와 공개 `period_start/end`의 연도 범위, LME/국가 **기록 메타데이터**, 조사 지점·선별 기록·불확실성 결측, 출처별 원문 URL·이용조건을 표시한다. 국가 메타데이터가 곧 국가 관할권이란 뜻은 아니다. 출처/연도/해역이 빠지면 그 결측도 보류 사유로 표시한다.
- 시연 격자는 기록 연도와 OBIS 조회 URL·종 전체 출처 수만 연결한다. **개별 격자에 어느 출처의 몇 건이 들어갔는지**는 스냅샷에서 알 수 없어 제공처를 셀별로 임의 배정하지 않는다. 출처별 링크·라이선스는 종 상세의 기존 인용 목록과 PR #7의 출처표로 확인한다.
- 출현 기록 건수는 관측 노력, 동정, 조사 수단, 기간 및 공개 조건에 영향을 받는다. 일부는 국경 밖 조사다. 출현을 현재 한국 전체 분포·개체수·자원량·개체군 감소로 외삽하지 않는다. 공개 셀은 민감도 검토를 거친 1° 영역만 보여주며 원좌표나 레코드 ID를 만들거나 복원하지 않는다.

## 향후 해역별 판단을 허용하기 위한 검수 게이트

| 게이트 | 이번 단계의 상태와 필요한 검수 |
| --- | --- |
| 1. 종별 지표 | 승인 학명·AphiaID에 결속된 검수 BBVI·MCUI, 기준일, 분모·원출처·불확실성. 현재 실제 점수 파일 없음. 시범 점수만으로 공공 해역 판단 승인 불가. |
| 2. 종–셀 연결 | 동일 종·AphiaID와 셀의 기록 품질 및 기간을 검수하고, **종별 지표를 셀로 투영할 과학적 근거**를 정의. 현재 셀은 출현만 뜻하므로 미충족. |
| 3. 셀 집계 규칙 | 둘 이상 종이 한 셀에 등장할 때 중복·값 분포·서식 적합성·민감종·다른 단위의 기여를 처리하는 명시적 결합식과 불확실성. 합·평균·최댓값 중 어느 것도 임의 선택 불가. |
| 4. 해역 간 비교 | 관측 노력과 수집 편향, 기록 중복, 연구 시기 차이, 격자 면적·해안선/국경 통과, 외래/양식 기록 등을 검토·보정하고 독립 자료로 사후 검증. 현재 미충족. |
| 5. 공개 승인 | 출처·이용조건, 평가 범위/연도, 좌표 민감도, 판단 기준일과 전문가 검수를 해역별 출력에 묶는다. 현재 해당 출력·승인 없음. |

UI의 `cellAssessmentStatus`는 **위치 판단 승인 경로를 제공하지 않는다.** 종별 점수가 들어와도 셀 귀속/비교 규칙이 검증되지 않은 한 보류 상태를 유지한다. 미래에는 별도 검수된 해역 분석 결과의 버전·집계법·출처를 가진 공개 아티팩트와 다층 검증을 설계해야 한다. 출현 셀에 숫자 BBVI·MCUI를 일괄 복사하는 방식은 금지한다.

## 검증

`node --check dist/app.js` 및 `node verification/test_map_boundary.mjs`: 실제 점수 없음/가상의 종 점수가 있어도 해역 판단 0, 공개 셀 팝업의 기간·해역 메타데이터·원문·이용조건·보류 사유, 누락 항목 보류, 시연과 운영 격자 구분을 확인한다. 이는 브라우저 시각 검수나 운영 공개 API의 원행 감사가 아니다. 이 브랜치는 배포하지 않는다.
