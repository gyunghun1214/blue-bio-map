# 신규 22종 OBIS 범위 조회와 공개 판단 (2026-09-26)

## 결과의 범위

- WoRMS AphiaID의 승인 종명·Species 상태를 API에서 다시 확인한 뒤 OBIS의 한반도 시험 범위(124–132°E, 33–38.7°N)에 `size=0`으로 질의했다. 22종 모두 응답을 받았다. 종별 조회 URL·시각은 `dist/expansion-evidence.json`의 `obis`에 있다.
- 21종은 검색 결과가 있고 시카메굴은 이 질의의 결과가 0건이다. 합계 8,870은 **종별 검색 응답 수의 합계**이며 중복을 제거한 기록 수나 개체수·자원량이 아니다. `taxonid` 검색에는 하위 분류군이 포함될 수 있어 종명 일치도 다시 검수해야 한다.
- 원자료는 `size=0`으로 요청했으며 이번 조회에서 개별 기록, 원좌표, 출처 데이터셋, 기록/데이터셋 라이선스, 좌표 품질, 육지 여부, 양식 여부, 관측 중복, 민감도를 확인하지 않았다. **신규 공개 셀 0개, 신규 지표 0건.** 기존에 독립 검수한 피조개의 1930년 GBIF 표본 4° 셀 1개만 유지한다.
- GBIF의 기존 8,333건 조회와 이번 OBIS의 8,870건 질의 응답은 서로 다른 검색·분류·중복·권리 범위이므로 합산하지 않는다. GBIF 잠정 품질 통과 15건 중 공개 승인된 것은 피조개 역사 표본 1건이다.
- 영양 열은 RDA 식품명 후보일 뿐 목표 종 학명과 시료가 연결되지 않았다. IUCN 열은 체크리스트의 범주 메타데이터이며 원평가의 현행성·평가 기준은 확인 전이다. 생리활성의 종→화합물→정량 시험→논문 연결은 아직 검수되지 않았다. 네 지표 모두 보류다.

## 공개 보류 해제 조건

1. OBIS 종별 전체 기록을 조회해 정확한 종 또는 적절한 동의어만 남기고, 해당 기록과 데이터셋의 출처·이용조건을 확인한다. 현재 검색 건수만으로는 공개 승인할 수 없다.
2. GBIF·OBIS 간 및 데이터셋 내 중복, 기록 연도, 좌표 불확실성, 육지·해안선, 사육·양식·반입 가능성을 기록별로 검수한다. 오류와 실패는 0건으로 치환하지 않는다.
3. 남획 위험을 검토하고 승인 기록만 집계한다. 민감종·오래된 단독 기록은 4° 이상 일반화 또는 비공개로 결정한다. 원좌표와 개별 기록 ID를 배포물에 넣지 않는다.
4. 영양 원행과 종 동정·가식부·시료 상태·양식 근거를 대조하고, 생리활성의 확정 화합물/정량 assay 사슬과 IUCN 원평가의 현행성을 검수한 후에만 축별 지표를 심사한다.

## 재현

```bash
python scripts/collect_expansion_obis_summary.py
python scripts/publish_expansion_obis_summary.py
python -m unittest verification.test_obis_summary
```

첫 명령은 네트워크 접속이 필요하며 임시 결과를 무시되는 `tmp/`에 쓴다. 두 번째 명령은 공개 가능한 검색 상태와 건수만 `dist/expansion-evidence.json`에 복사하며 기존 공개 셀·점수는 바꾸지 않는다. GBIF/RDA/IUCN 재생성 뒤에는 두 번째 명령을 다시 실행한다.

## 주요 원천과 이용조건

- [WoRMS REST API](https://www.marinespecies.org/rest/): 승인명·AphiaID 확인. 원문 인용은 종별 WoRMS 링크를 따른다.
- [OBIS API](https://api.obis.org/v3/): 이번 결과는 범위 검색 건수만 사용했다. 개별 데이터셋의 라이선스는 이번 단계에 확인하지 않았으므로 재배포·위치 공개를 승인하지 않았다.
- [GBIF Occurrence](https://www.gbif.org/occurrence/search): 기존 시험 조회. 데이터셋과 레코드별 조건은 `dist/expansion-evidence.json`에 분리해 기록됐다.
- [RDA 국가표준식품성분 DB](https://www.nics.go.kr/food/kfi/fct/fctFoodSrch/main): 학명 미기재 식품명 후보; 공공누리 제1유형 스냅샷. 종별 영양값으로 확정하지 않았다.
- [IUCN 게시 체크리스트](https://www.gbif.org/dataset/19491596-35ae-4a91-9a98-85cf505f1bd3): 범주 메타데이터. 원평가 재검수 전 MCUI 보류.
