Subject: Permission question — using AHTPDB IC50 values in a non-commercial research prototype

Dear Prof. Raghava,

We are a student team preparing a non-commercial research prototype, "Blue-bio Value Map", for the Ocean 20 Challenge. The prototype summarises marine species evidence for Korean waters.

We would like to use AHTPDB (Kumar et al., 2015, Nucleic Acids Research 43:D956–D962) as follows:

1. We would use the IC50 download (pepic50.txt, retrieved 2026-09-26). From it we would select the peptides tested against ACE with the HHL substrate, and use them as a fixed comparison set.
2. We would publish only derived percentile values for a few species (for example *Undaria pinnatifida* and *Magallana gigas*), the AHTPDB row IDs we used, and a citation of your paper. We would not redistribute the file itself or the peptide sequence list.

We found two different terms. The repository README states CC BY-NC 4.0, but the LICENSE file in the same repository is MIT. Could you tell us:

- which terms apply to the AHTPDB data, and
- whether the use described above is acceptable, and what attribution you would like?

Thank you for maintaining this resource.

Kind regards,
(팀 이름 · 연락처 — 발송 전 기입)
