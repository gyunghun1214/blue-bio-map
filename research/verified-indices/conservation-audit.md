## 조회 범위와 확인 한계

- 운영 후보는 2026-09-25에 공개 API의 `species_profiles`에서 읽은 [8종 동결 목록](candidates.json)을 따른다. 종별 원평가 검색은 승인 학명, 위의 두 구명, `site:iucnredlist.org/species`, IUCN DOI/평가 ID를 조합했다. [PR #7 조사](https://github.com/gyunghun1214/blue-bio-map/pull/7)는 탐색 단서로 검토했으며 지표 입력을 승인하는 근거로 사용하지 않았다. 특히 그 조사에는 살오징어의 2014년 IUCN 평가가 누락되어 있다.
- IUCN 종별 원사이트 페이지는 이번 조회 환경에서 HTTP **403**이었고, [IUCN API v4](https://api.iucnredlist.org/)는 토큰이 필요하다. 공식 API는 [2026-1](https://nrl.iucnredlist.org/resources/summary-statistics) 데이터를 안내하지만 토큰 없는 현재판 종별 조회는 완료되지 않았다. SeaLifeBase의 2025-2 전재는 **공식 2026-1 조회를 대체하지 못한다**.
- IUCN의 [평가 절차](https://nrl.iucnredlist.org/assessment/process)는 10년이 지난 평가를 공식적으로 오래된 평가로 보며, [평가 정보 안내](https://nrl.iucnredlist.org/assessment/supporting-information)는 이런 사실표에 `Needs updating` 주석이 달릴 수 있음을 설명한다. 두 종의 2010년 평가일은 2026년에 이 기준을 넘는다. 오래됐다는 사실만으로 등급이 자동 변경되거나 공식 레코드가 삭제됐다고 단정하지 않지만, 현재 위험도를 확인한 값으로 말하지 않는다.
- IUCN [이용조건](https://www.iucnredlist.org/terms/terms-of-use)과 [API 이용 안내](https://api.iucnredlist.org/)를 확인해야 한다. 이 저장소에는 원평가 PDF·대량 원자료를 복제하지 않고 평가 ID, DOI, 최소 사실 요약과 링크만 남긴다. 상업적 API 사용은 허용되지 않는다고 API 안내에 명시되어 있다.

## MCUI와 출현자료의 경계

현 단계에서 8종의 **현행 평가 확인을 완료한 MCUI 입력은 0건**이다. 돌기해삼의 과거 EN과 살오징어의 과거 LC 전재값은 원등급·평가일·범위를 함께 보여줄 수 있으나, 검증 전 시범 MCUI 숫자 또는 실제 매트릭스 위치로 자동 변환하지 않는다. 현재판을 공식 원레코드로 확인하게 되면 IUCN 등급과 자체 시범 숫자 매핑을 나란히 공개하고, 평가 시점·지리 범위와 `출현 추세 교차검증 미완료`를 명시한다.

OBIS·GBIF의 원시 출현 건수나 공개 1° 셀의 증감은 개체군 감소율이 아니다. 중복, 조사 노력, 시기와 공간 범위를 통제한 별도 검수 없이는 MCUI에 가감하지 않는다. 종별 평가를 그 종이 출현한 모든 셀의 해역별 보전 등급으로 복사하지 않는다.

## 다음 원자료 작업

1. IUCN 공식 웹 접근 또는 합법적으로 발급된 API v4 토큰으로 **2026-1**의 정확한 승인 분류군, 최신 전 지구/지역 평가 ID, 원등급·기준, 평가일·발표연도, 근거, 대체/정정 이력을 8종 각각 조회한다. 조회 결과가 없는 종은 이름의 동의어·분류 변경을 확인하고, 그때도 `NE`를 추정하지 않는다.
2. 살오징어 2014년 원평가 본문에서 LC·2010-05-10·전 지구 범위·근거를 직접 대조한다. SeaLifeBase 전재를 `reviewed: true` 근거로 쓰지 않는다.
3. 공식 현재판 확인 기록에는 평가 ID/DOI와 별도 `checked_on`, 확인한 버전, 확인 경로를 남긴다. 10년 초과 `Needs updating`도 그대로 표시한다. 보존·공개 이용조건을 검토한 뒤에만 계산 입력으로 승격한다.
