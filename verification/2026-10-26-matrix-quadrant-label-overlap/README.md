# 매트릭스 사분면 이름표가 점·밀집 구간 버튼을 피하게 (2026-10-26)

비교와 지표 탭 '활용 × 보전' 매트릭스의 사분면 이름표(두 줄)가 점·밀집 구간 버튼·보이는 점 이름을 피해 자리를 잡는다. 점 위치·크기·색, 기준선, 축 눈금·축 이름, 이름표 문구·색, 글자 크기, 매트릭스 높이는 그대로다.

- 지침: [`prompt-original.md`](prompt-original.md) (LKH가 보낸 `prompts/matrix-quadrant-label-overlap-claude-code.md`, 저장소에는 `prompts/` 폴더가 없다)

## 먼저 확인한 것

1. **이름표 마크업·배치.** `index.html`의 `#matrix .quadrant.q1~q4` 안 `<strong>`(색 원 + 쉬운 이름)과 `<span>`(공식 유형 이름, `renderMatrixTypes`가 채움). 자리는 CSS뿐이었다: 사분면이 세로 flex라 q1·q2는 위, q3·q4는 PC에서 아래(`compare.css` `justify-content:flex-end`), 740px 이하에서는 위(`justify-content:flex-start`), q2·q4는 오른쪽 맞춤. `app.js`는 이름표를 옮기지 않았다.
2. **점·버튼·점 이름.** `renderMatrix`가 `.matrix-point` 단추(안에 `.point-label`)를 `left:BBVI%`·`bottom:MCUI%`로 그리고, `declutterPointLabels`가 `spreadMatrixPoints`(같은 높이 점 위아래로 비킴) → 점 이름 자리 고르기 → `drawMatrixClusters`(점선 묶음 `.matrix-cluster`, 버튼 `.matrix-cluster-btn`) 순으로 놓는다. 층: 격자 `.matrix-ticks` z-index 1, 이름표 글자 z-index 2(사분면 안), 점 z-index 2(DOM에서 뒤라 이름표 위), 밀집 구간 버튼 z-index 8.
3. **이미 있던 회피.** 점 이름은 서로·점을 피하고, 밀집 구간 버튼은 사분면 이름 글자를 피했다(`drawMatrixClusters`의 `names`). 영어 화면에서는 선택하지 않은 점 이름도 사분면 이름을 피했다. 이름표 자신은 아무것도 피하지 않았다. 같은 방식(사각형 목록 + 교차 넓이)을 쓰되, 이름표는 점·이름·버튼이 다 놓인 **뒤에** 마지막으로 자리를 고른다.
4. **겹침 표.** 아래.

## 한 일

- **이름표 한 덩어리.** 두 줄(`strong`·`span`)을 `<div class="q-name">`으로 감쌌다. 두 줄은 늘 함께 보이고 함께 움직인다. 문구·색·글자 크기는 그대로, 숨김·말줄임 없음. '현재 0종'(`.q-empty`)은 지금처럼 사분면 가운데에 남는다.
- **자리 고르기(`placeQuadrantNames`).** 점·점 이름·밀집 구간 버튼이 다 놓인 뒤 한 번 잰다(`getBoundingClientRect`, 반복 배치 없음). 이름표 글자 덩어리(두 줄 전체) + 6px과 점(지름 + 4px)·밀집 구간 버튼·보이는 점 이름(휴대폰에서 숨은 이름은 뺀다)·눈금 숫자의 교차 넓이를 자기 사분면의 네 모서리(지금 자리 → 옆 → 위아래 → 맞은편)에서 비교해 가장 작은 곳, 같으면 앞 순서. 지금 자리가 비어 있으면 옮기지 않는다.
- **바깥 자리.** 네 곳이 모두 걸리면 두 줄 그대로 그래프 밖으로: 위 두 사분면은 그래프 위(휴대폰의 `보전 시급성 MCUI ↑` 줄과 '가상 작동 예시' 표시보다 위), 아래 두 사분면은 `활용가치 BBVI →` 아래. 가로는 그 사분면 폭 안. 매트릭스 틀(`.matrix-frame`)의 위·아래 안쪽 여백만 필요한 만큼 늘리고, 그래프 높이는 그대로 둔다(PC처럼 패널 높이에 맞춰 늘어나는 그래프는 잰 높이를 `min-height`로 지킨다). 점 위치는 바뀌지 않는다.
- **층과 바탕.** `.q-name`은 z-index 2로 점(DOM에서 뒤)·버튼(z-index 8) 아래, `pointer-events:none`이라 점 누르기를 막지 않는다. 글자 뒤 바탕은 `--cs-panel` 70%(`color-mix`, 안 되는 브라우저는 같은 색 rgba .7), 반경 6px, 안쪽 여백 2px 6px. 같은 크기의 음수 바깥 여백으로 글자 자리는 그대로다.
- **다시 계산하는 때.** 매트릭스를 그릴 때(`declutterPointLabels` 끝, 시작에서 이름표·여백을 먼저 되돌린다), 분류·검색이 바뀔 때(`applyCompareFilter` 끝: 분류 안내 줄이 PC 그래프 높이를 바꾼다), 선택 종이 바뀔 때, 비교 담기로 휴대폰 점 이름이 보이거나 숨을 때(`markBasketPoints`), 가상 작동 예시(`renderMatrix`), 창 크기가 바뀔 때(기존 150ms 디바운스). 비교 기준(가중치)을 바꾸면 종 프로필이 패널 높이를 바꾼 **뒤에** 매트릭스를 한 번 더 배치한다(`redrawForWeight`, 같은 작업 안이라 중간 화면이 그려지지 않는다). 이 한 줄이 없으면 PC에서 바뀌기 전 그래프 높이로 이름표 자리를 재게 된다(1440px MFPI 0.00: 배치할 때 405px, 프로필이 바뀐 뒤 430px).
