# 같은 순간의 화면 비교 (클라우드, 2026-10-19)

`frames.mjs`로 수정 전(main 4494a95)과 수정 후(406e5c5)를 같은 순간에 찍어 픽셀마다 비교했다. 페이지의 시계(`performance.now`와
requestAnimationFrame)를 멈춰 두고 16ms씩 진행시키므로 두 쪽이 정확히 같은 시각의 장면이다. 클라우드 Chromium(SwiftShader)이라
색 계산은 실제 GPU와 조금 다를 수 있지만, 두 쪽이 같은 환경이라 차이는 코드 차이만 남는다. 차이 그림(×8)은 PNG 원본에서 만들었고,
3초·5.5초·7.5초 577×549는 이 폴더의 `577x549-t*.jpg`(왼쪽 수정 전, 가운데 수정 후, 오른쪽 차이 ×8)로 볼 수 있다.

읽는 법: 평균 차이가 1 미만이고 24단계 넘게 다른 픽셀이 사실상 0이면 눈으로 구별되지 않는다. 8단계 넘는 차이는 파문 고리 가장자리
(2D 캔버스의 선 긋기와 셰이더의 면적 계산이 픽셀 경계에서 갈리는 안티에일리어싱)에만 있다. 5–6초에 화면의 60% 남짓이 1단계(0–255 중 1)
다른 것은 글자가 사라진 뒤의 로더 시트를 CSS 대신 셰이더가 칠하며 생긴 그라디언트 반올림 차이다(577×549 5.5초: 0단계 34%, 1단계 59%,
2단계 5%, 3–8단계 2.3%, 8단계 초과 0.17%). 아래 '잡음 기준'은 수정 전 main을 두 번 찍어 비교한 값이다.

## 다시 찍는 법

```
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist      # 수정 후
python3 -m http.server 8766 --bind 127.0.0.1 --directory <main 체크아웃>/dist
node verification/2026-10-19-intro-jank/frames.mjs shoot out/before --url http://127.0.0.1:8766/ --size 577x549 --dpr 1.5
node verification/2026-10-19-intro-jank/frames.mjs shoot out/after  --url http://127.0.0.1:8765/ --size 577x549 --dpr 1.5
node verification/2026-10-19-intro-jank/frames.mjs compare out/before out/after out/diff
```

클라우드(GPU 없음)에서는 `--headless --hwgl`과 `CHROME_FLAGS="--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist"`,
2D 경로는 `--hwgl` 없이, 움직임 끄기는 `--reduce`를 붙였다. 순간은 `--at 1.6,2.2,3,...`.
