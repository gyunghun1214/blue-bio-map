# 멍이 버튼 키우기 + 사용자가 원하는 자리로 옮기기 — Claude Code 작업 지침

## 배경

화면 오른쪽 아래에 떠 있는 멍이 버튼(우렁쉥이 캐릭터)은 휴대폰(390px)에서 가로 38px 안팎으로 보인다.

- 손가락으로 누르기 편한 최소 크기(44px)보다 작고, 캐릭터 표정이 잘 보이지 않는다.
- 고정된 자리라서 화면마다 무언가를 가린다. 탐색 지도에서는 신약 칩 줄의 '기생충' 칩 끝을, 비교와 지표에서는 매트릭스 x축 눈금 `100`을 가린다.

이 작업은 두 가지다.

1. 멍이를 **조금 키운다.**
2. 사용자가 멍이를 **끌어서 원하는 자리로 옮길 수 있게** 한다. 가리는 문제는 사용자가 직접 비켜 놓으면 풀린다.

멍이의 그림, 표정, 누르면 하는 일은 바꾸지 않는다.

- 저장소: `gyunghun1214/blue-bio-map`, 최신 `main`에서 시작
- 작업 브랜치: 세션에 지정된 브랜치. 없으면 `ui/meongi-bigger-draggable`
- 이전 작업 지침들의 "멍이는 건드리지 않는다"는 이 작업에는 해당하지 않는다. 이 작업이 멍이를 다루는 지침이다.

## 먼저 확인할 것 (README에 적는다)

1. 멍이 버튼의 마크업·선택자, 위치 지정 방식(`position:fixed`, `right`/`bottom` 값), 크기 규칙이 있는 CSS 파일
2. 멍이를 누르면 무엇이 열리는지(말풍선, 안내 패널 등). 그 패널이 멍이 위치를 기준으로 자리를 잡는지
3. 멍이가 나오는 화면: `index.html`의 네 탭, `expedition.html`. 같은 코드를 함께 쓰는지
4. 화면 아래 탭 줄, 휴대폰 아래 시트, 비교 탭 담기 트레이, 브라우저 하단 주소창(`env(safe-area-inset-bottom)`)과 멍이의 지금 간격
5. 멍이에 이미 움직임(둥실거림 등)이 있는지, '움직임 줄이기'일 때 어떻게 되는지

## 할 것

### 1. 크기

- 휴대폰(`max-width:740px`): 보이는 크기를 **52px 안팎**으로 키운다(지금보다 약 1.35배). 누르는 영역은 **56×56px 이상**이다(보이는 그림보다 클 수 있다).
- PC(741px 이상): 지금 크기가 52px보다 작으면 같은 비율로 키우되 64px을 넘기지 않는다. 지금 크기가 이미 충분하면 그대로 둔다(README에 판단을 적는다).
- 그림은 비율을 유지한 채 키운다. 흐려지지 않게 원본 해상도(SVG면 그대로, 비트맵이면 2배 이상 자산이 있는지)를 확인한다. 자산이 모자라면 README에 적고 새 그림은 만들지 않는다.
- 기본 자리: 오른쪽 아래. 화면 오른쪽 끝에서 16px, 아래 탭 줄 위에서 12px 띄운다(`env(safe-area-inset-bottom)` 포함). 아래 시트·담기 트레이가 올라와 있으면 그 위로 비킨다(지금 이미 비키는 장치가 있으면 그것을 쓴다).

### 2. 끌어서 옮기기

- **포인터 이벤트**(`pointerdown` / `pointermove` / `pointerup` / `pointercancel`)로 만든다. 마우스·터치·펜을 한 코드로 처리한다. 멍이 요소에 `touch-action:none`을 주고, 끄는 동안 `setPointerCapture`를 쓴다.
- **누르기와 끌기 구분**: 누른 뒤 **8px 이상** 움직이면 끌기로 본다. 그보다 적게 움직이고 떼면 지금처럼 누르기(멍이가 하는 일 실행)다. 끌기로 끝났을 때는 누르기 동작을 실행하지 않는다.
- **길게 누를 필요 없이 바로 끌리게** 한다. 단, 끄는 동안에는 지도 이동, 아래 시트 끌기, 페이지 스크롤이 함께 일어나지 않게 이벤트 전파를 막는다(`stopPropagation`, 지도 위에서는 Leaflet 드래그가 반응하지 않는지 확인).
- **놓을 수 있는 범위**: 화면 안, 위쪽 헤더(`Blue-bio · EN · 연구 프로토타입` 줄) 아래부터 아래 탭 줄 위까지다. 좌우 끝에서 8px 안쪽이다. 범위 밖으로 끌면 가장자리에 붙어 멈춘다.
- **놓으면 가까운 좌우 가장자리로 붙는다**(가로만, 세로는 놓은 자리 그대로). 붙는 움직임은 200ms 안팎이다. '움직임 줄이기'(사이트 스위치 또는 `prefers-reduced-motion`)이면 애니메이션 없이 바로 붙는다.
- 끄는 동안 멍이를 살짝 키우고(1.08배) 그림자를 진하게 해 들려 있다는 것을 보여 준다. 손을 떼면 원래대로다.
- **PC 마우스**: 끌기는 휴대폰과 똑같이 마우스로 바로 된다(같은 포인터 이벤트 코드). 마우스를 올리면 커서가 `grab`, 끄는 동안 `grabbing`이다(`@media (hover:hover) and (pointer:fine)` 안에서). 끄는 동안 글자가 선택되거나 브라우저 기본 이미지 끌기가 일어나지 않게 `user-select:none`, 그림에 `draggable="false"`를 준다.
- **자리 기억**: 놓은 자리를 이 기기에만 저장한다. `localStorage` 한 항목에 `{side:"left"|"right", y:<화면 높이 대비 비율>}`로 저장하고, 읽고 쓸 때 `try/catch`로 감싼다. 저장이 안 되는 환경(비공개 창 등)에서는 기본 자리로 시작한다. 비율로 저장하므로 화면 크기가 바뀌어도 비슷한 높이에 놓인다.
- **화면 크기가 바뀔 때**(회전, 창 크기 조정, 시트·트레이가 올라올 때): 저장한 자리가 범위 밖이 되면 가장 가까운 범위 안 자리로 옮긴다. 저장값은 사용자가 다시 옮기기 전까지 바꾸지 않는다.
- 멍이를 누르면 열리는 패널이 멍이 위치를 기준으로 자리를 잡는다면, 멍이가 왼쪽에 있을 때는 패널이 오른쪽으로 펼쳐지는 식으로 화면 밖으로 넘치지 않게 맞춘다. 패널 내용은 바꾸지 않는다.
- 멍이 패널이 열려 있는 동안에는 끌기를 막지 않는다. 끌기를 시작하면 패널을 닫는다.

### 3. 스크롤하는 동안 흐려지기

- 페이지나 스크롤 상자(아래 시트, 패널 안 목록 등)를 스크롤하는 동안 멍이를 **불투명도 0.35, 크기 0.85배**로 줄인다. 그 밑 내용이 비쳐 보이게 하기 위해서다.
- 스크롤이 **멈추고 약 400ms 뒤** 원래대로 돌아온다. 줄고 돌아오는 움직임은 150~200ms 안팎이다.
- **자리는 바꾸지 않는다.** 크기를 줄일 때 기준점(`transform-origin`)은 멍이가 붙은 가장자리 쪽이라, 줄어들어도 그 자리에 있는 것처럼 보인다.
- 감지 방식: `scroll` 이벤트를 `document`에 **캡처 단계, `passive:true`**로 한 번만 달아 모든 스크롤 상자를 함께 잡는다. 이벤트마다 스타일을 바꾸지 말고 class 하나(예: `is-scrolling`)를 붙이고 떼는 것만 한다. 떼는 시점은 디바운스 타이머로 정한다.
- 지도를 끌어 옮기거나 확대하는 것은 스크롤이 아니므로 흐려지지 않는다.
- 흐려진 동안에도 멍이는 누를 수 있다. 누르거나 끌기 시작하면 바로 원래대로 돌아온다.
- 키보드 포커스가 멍이에 있으면 흐려지지 않는다(포커스 링이 잘 보이게).
- '움직임 줄이기'(사이트 스위치 또는 `prefers-reduced-motion`)이면 크기는 줄이지 않고 불투명도만 애니메이션 없이 바꾼다.

### 4. 키보드·접근성

- 키보드 이동은 마우스·손가락 끌기를 **대신하는 것이 아니라 덧붙이는 것**이다. 끌기를 쓸 수 없는 사용자를 위해 키보드로도 옮길 수 있게 한다. 멍이에 포커스가 있을 때 **Shift + 방향키**로 16px씩 옮기고, 좌우 방향키는 반대편 가장자리로 넘긴다. 그냥 Enter·Space는 지금처럼 누르기다.
- **처음 자리로 되돌리기**: 멍이를 키보드 포커스한 상태에서 **Shift + Home**을 누르거나, 멍이를 **두 번 빠르게 누르면**(300ms 안) 기본 자리로 돌아가고 저장값을 지운다. 두 번 누르기가 지금 멍이의 다른 동작과 겹치면 두 번 누르기는 빼고 키보드만 둔다(README에 적는다).
- 멍이 버튼의 기존 접근 가능한 이름(`aria-label`)은 지우지 않는다. 뒤에 "끌거나 Shift와 방향키로 옮길 수 있습니다"를 덧붙인다.
- 옮긴 뒤 스크린리더에 위치를 알리는 실시간 알림은 만들지 않는다(과한 알림 방지).

### 5. 만드는 방식

- CSS는 새 파일 **`dist/meongi.css`**에 모으고 맨 위에 설명 주석을 단다. `index.html`(멍이가 나오는 다른 페이지도 같은 코드를 쓰면 그 페이지도)에서 모든 CSS 중 마지막에 불러온다. 기존 크기 규칙은 지우지 말고 같은 선택자로 덮어쓴다.
- JS는 멍이를 만드는 기존 코드 옆에 둔다. 새 라이브러리를 들이지 않는다.
- `expedition.html`의 멍이가 다른 코드라면 이번에는 **`index.html`만** 바꾸고 README에 적는다. 같은 코드면 두 페이지가 같이 바뀌는지 확인한다.

## 절대 바꾸지 않을 것

- 멍이 그림·표정·색, 둥실거림 같은 기존 움직임(끄는 동안에는 잠시 멈춰도 된다)
- 멍이를 누르면 하는 일, 패널 내용과 문구
- 각 탭의 `textContent`(멍이 `aria-label` 덧붙임만 허용)
- 아래 탭 줄, 시트, 담기 트레이, 지도 확대·이동 동작
- `scripts/`, `config/`, `dist/*.json`, 지표 값

## 검사

1. 먼저 멍이에 묶인 검사를 찾는다. `verification/` 아래에서 멍이의 실제 class, `mascot`, `멍이`, `meongi`로 검색한다. 크기·위치를 고정값으로 기대하는 검사는 **기대값을 고친다**. 지우거나 건너뛰지 않는다.
2. 새 검사를 더한다(Playwright/uicheck 방식).
   - 390px: 멍이 누르는 영역이 56×56px 이상이다. 기본 자리가 아래 탭 줄과 겹치지 않는다.
   - 3px만 움직였다 떼면 누르기 동작이 실행되고 자리는 그대로다.
   - 40px 끌었다 떼면 누르기 동작이 실행되지 않고, 가까운 좌우 가장자리에 붙으며, 세로 위치는 놓은 자리다.
   - 범위 밖(헤더 위, 탭 줄 아래, 화면 밖)으로 끌어도 범위 안에 멈춘다.
   - 지도 위에서 멍이를 끄는 동안 지도 중심(`map.getCenter()`)이 바뀌지 않는다. 시트 위에서 끌 때 시트 높이가 바뀌지 않는다.
   - 다시 불러와도 놓은 자리가 유지된다. `localStorage`를 막은 상태에서도 오류 없이 기본 자리로 뜬다.
   - 390px → 768px → 390px로 바꿔도 멍이가 화면 안에 있다.
   - Shift + 방향키로 움직이고, Shift + Home으로 기본 자리로 돌아간다.
   - 페이지를 스크롤하는 동안 멍이에 `is-scrolling`이 붙고(불투명도 0.35 안팎), 스크롤을 멈추고 약 400ms 뒤 떨어진다. 아래 시트 안을 스크롤해도 같다. 스크롤 전후로 멍이의 자리(`left`/`top`)가 같다.
   - 지도를 끌어 옮기거나 확대할 때는 `is-scrolling`이 붙지 않는다.
   - 멍이에 키보드 포커스가 있을 때는 스크롤해도 흐려지지 않는다.
   - 네 탭 `textContent`가 전후로 같다(멍이 `aria-label` 제외).
3. CI 전체(`verify.yml`의 `node verification/test_*.mjs`, `python scripts/build_expedition_stops.py --check`, `python -m unittest discover -s verification -p 'test_*.py'`)와 로컬 `verification/uicheck.mjs`를 돌린다.
4. 직접 확인한다.
   - iOS Safari·Android Chrome 실제 기기에서 끌기가 매끄럽고, 끄는 동안 페이지가 스크롤되거나 화면이 확대되지 않는다.
   - PC에서 마우스로 끌 수 있고, 끈 뒤 글자가 선택되지 않는다(`user-select:none`).
   - '움직임 줄이기'를 켜면 붙는 애니메이션이 없고, 스크롤할 때 크기가 줄지 않는다.
   - 빠르게 오래 스크롤해도 화면이 버벅이지 않는다(성능 기록에서 스크롤 중 긴 작업이 늘지 않는지 본다).
   - 360~1440px에서 가로 넘침이 없고, 콘솔 오류가 없다.
5. CSS를 더하고 JS를 고쳤으므로 `dist/_headers` immutable 목록에 `/meongi.css`를 넣는다. `index.html`의 `?v=` 해시도 다시 계산한다(README 53행 규칙, LF로 맞춘 파일 내용 sha256 앞 10자, `test_client_outdated.mjs`).
