# 탐색 후보 카드: 유형 배지가 카드 안쪽 여백을 넘던 문제 (2026-10-18)

기준 커밋 2c0e672. 요청: LKH의 `neon-card-badge-fix-prompt.pdf`. 원본을 main과 대조해 고친 v2 지침은 프로젝트 파일 `neon-card-badge-fix/prompt-v2.md`.

- 원인: 데스크톱(1180px 이상) 카드 둘째 줄(`활용 · 보전 · 유형 배지`)은 줄바꿈 없는 flex이고 배지가 `margin-left:auto`로 오른쪽 끝에 붙었다. 목록 폭이 340px 이하이면 `@container sclist` 규칙이 배지를 셋째 줄로 내렸지만, 목록이 그보다 넓은 화면(약 1450px 이상, 사이드바 `clamp(320px,23.5vw,380px)`)에서는 한 줄에 남아 오른쪽 안쪽 여백(14px)과 테두리까지 밀고 나갔다.
- 수정(`dist/theme.css` 탐색 지도 1180px 이상 블록): 배지를 모든 폭에서 점수 아래 셋째 줄로(`flex:0 0 100%`, 간격은 1440px 배치 그대로 가로 22px·세로 10px), 둘째 줄은 `flex-wrap:wrap`. 배지 글자 말줄임과 종 이름 말줄임(`minmax(0,max-content)` 칸, `min-width:0`)은 실제 배치보다 훨씬 좁을 때만 쓰이는 안전장치. 쓸모가 없어진 `@container sclist` 블록은 지움.
- `dist/app.js`: 종 이름 `<b>`와 학명 `<em>`에 전체 이름 `title`(잘린 학명을 툴팁으로).
- 바꾸지 않은 것: 유형 이름 글자, 점수 숫자 크기(23px), 배지 글자 크기(14px), 체크박스 위치, 테두리·그림자·색·hover·선택 스타일, 유형 기호, 휴대폰·741–1179px 배치. 카드 전체 `overflow:hidden`은 쓰지 않음.
