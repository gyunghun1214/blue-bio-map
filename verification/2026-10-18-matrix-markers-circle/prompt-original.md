# 2×2 유형 표시 모양(▲ ◆ ● ■, 마름모 점)을 원 하나로 통일, 색으로만 구분 — Claude Code 작업 지침

## 배경

탐색 지도와 비교와 지표는 2×2 유형을 **색과 모양 두 가지로** 나타낸다. 그런데 모양 체계에 두 가지 문제가 있다.

1. **한 모양이 두 뜻을 가진다.** 사분면 이름에서 ◆는 '두 지표 모두 높음'이다. 하지만 매트릭스 점에서 마름모는 '자원 감소 신호로 정한 MCUI'다(비교 탭 '읽는 법': "점 색은 유형, 마름모 점은 자원 감소 신호로 정한 MCUI입니다"). 그래서 활용 높음 사분면에 있는 종이 자원 감소 신호를 받으면 ■인지 ◆인지 정할 수 없다.
2. **지금도 사분면 모양이 지켜지지 않는다**(2026-10-18 배포본 화면).
   - 매트릭스: 사분면 이름은 ▲ ◆ ● ■인데, 점은 대부분 원이다. 보전 지표 높음에 있는 전복(종 수준)·해삼은 빨간 **원**이고, 살오징어는 빨간 **마름모**다. 두 지표 모두 낮음의 참조기는 파란 **마름모**다. 활용 지표 높음의 참굴·톳은 초록 **원**이다.
   - 탐색 지도 종 목록 카드: 이름 앞과 유형 배지에는 ▲ ■ ●를 쓴다. 같은 종이 매트릭스에서는 원으로 그려진다.

유형은 이미 **색**(네 유형 색, `matrixTypeColour`)과 **위치**(매트릭스에서 점의 사분면)와 **글자**(배지·사분면 이름)로 전달된다. 모양은 정보를 더하지 않고 혼란만 만든다. 이 작업은 **탐색 지도와 비교와 지표에서 유형 표시 모양을 모두 원(●)으로 바꾸고, 색 구분은 그대로 두는 것**이다. **화면 표시만 바꾼다.**

- 저장소: `gyunghun1214/blue-bio-map`, 최신 `main`에서 시작
- 작업 브랜치: 세션에 지정된 브랜치. 없으면 `ui/matrix-markers-circle`

## 먼저 할 일: 모양을 쓰는 곳 전부 찾기

아래 검색으로 모양을 그리는 곳을 모두 찾고, 결과 목록을 README에 남긴다. 아래 '할 것'의 목록은 화면에서 확인한 곳이다. 검색에서 더 나오면 같은 원칙으로 함께 고친다.

- `dist/` 전체(`app.js`, `compare.css`, `theme.css`, `style.css`, `index.html`)에서 검색한다.
  - 문자: `▲`, `■`, `◆`, `◇`, `◼`, `▴`, `△`, `□`
  - 이름: `shape`, `diamond`, `rhomb`, `마름모`, `triangle`, `square`, `tri`, `sq`, `dia`
  - SVG/CSS: `<polygon`, `<rect`(점·범례·배지 안), `rotate(45`, `clip-path`, `mask`
  - `matrixType`로 시작하는 보조 함수(색 말고 모양을 돌려주는 함수가 있는지 본다)
- 모양을 고르는 함수가 한 곳에 있으면, 그 함수가 **항상 원**을 돌려주게 바꾼다. 분기를 여러 군데에서 따로 고치지 않는다.

## 할 것

### 1. 비교와 지표 (`#compare`)

- **매트릭스 점**: 모든 종을 원으로 그린다. 마름모 분기(자원 감소 신호)를 없앤다.
  - 원 크기는 지금의 일반 원 점과 같다. 마름모가 일반 점보다 컸다면 일반 크기로 맞춘다.
  - **선택한 종**의 큰 원 + 실선 링, **공식값과 유형이 다른 종**의 점선 링은 그대로 둔다. 둘 다 모양이 아니라 원 둘레에 두르는 표시다.
  - 밀집 구간 점선 상자, 'N종 · 펼치기', 겹침 회피용 세로 비킴과 짧은 선은 그대로 둔다.
  - 점 툴팁의 MCUI 기반 문구(IUCN 전 지구 평가 · 한국 국가 평가 · 자원 감소 신호)는 그대로 둔다. 이제 자원 감소 신호는 툴팁과 숫자 옆 괄호(예: `60 (LC + 자원 감소)`)로만 읽힌다.
- **사분면 이름**: '보전 지표 높음 · 두 지표 모두 높음 · 두 지표 모두 낮음 · 활용 지표 높음' 앞의 ▲ ◆ ● ■를 모두 같은 크기의 원으로 바꾼다. 색은 유형 색 그대로다.
- **그래프 아래 범례**: '◆ 자원 감소 신호' 항목을 지운다. '선택한 종', '공식값과 유형이 다른 종', '밀집 구간' 항목은 그대로 둔다.
- **'읽는 법' 문구 한 줄**: 지금 문장은 사실과 맞지 않게 되므로 고친다.
  - 전: `두 값은 따로 봅니다 · 점 색은 유형, 마름모 점은 자원 감소 신호로 정한 MCUI입니다`
  - 후: `두 값은 따로 봅니다 · 점 색은 유형입니다 · 자원 감소 신호로 정한 MCUI는 숫자 옆 괄호와 점 툴팁에 적습니다`
  - '읽는 법'의 다른 문장은 한 글자도 바꾸지 않는다.
- **그 밖에 유형 모양이 나오는 곳**: 데이터 표의 유형 열, 종 프로필 머리, 그래프 아래 유형별 목록, '선택한 생물 비교' 창, 가중치 슬라이더의 탐색 보기 표시, '가상 작동 예시'. 모양 기호가 있으면 원으로 바꾼다.

### 2. 탐색 지도 (`#explore`)

- **종 목록 카드**: 이름 앞 표시와 오른쪽 아래 유형 배지(예: `■ 활용 지표 높음`, `▲ 보전 지표 높음`)의 기호를 원으로 바꾼다. 배지 글자와 색은 그대로 둔다.
- **오른쪽 패널(휴대폰은 아래 시트)과 근거 자세히 보기**: 유형 기호가 있으면 원으로 바꾼다.
- **'활용 × 보전' 지도 층의 범례**(MCUI ↑ / BBVI → 작은 2×2 범례)와 **'색의 의미'** 설명: 모양 기호가 있으면 원 또는 색 칸으로 바꾼다.
- **지도 셀 색**: 셀은 지금처럼 유형 색 채움이다. 바꾸지 않는다.

### 3. 범위 밖이지만 함께 고칠 한 문장 (`#method`)

모양을 없애면 '근거와 방법' 탭 '자료를 읽을 때'의 아래 문장이 사실과 달라진다. **이 문장만** 고친다.

- 전: `자원 감소 신호(KOSIS 어획량 추세)로 MCUI가 정해진 종은 마름모 점입니다.`
- 후: `자원 감소 신호(KOSIS 어획량 추세)로 MCUI가 정해진 종은 MCUI 숫자 옆 괄호에 ‘자원 감소’로 적습니다.`

'유형과 셀 색' 표(`renderTypeTable()`)가 공통 모양 함수를 써서 원으로 바뀌는 것은 허용한다. 그렇게 됐다면 README에 적는다. 표가 색 칸(스와치)이면 그대로 둔다.

## 색은 그대로, 접근성은 글자와 위치로

- 네 유형 색(`matrixTypeColour`)과 그 값을 쓰는 CSS 토큰은 바꾸지 않는다.
- 모양을 없애도 유형은 **색만으로 전달되지 않아야 한다**(WCAG 1.4.1). 다음을 확인하고 README에 적는다.
  - 목록 카드 배지와 사분면 이름에는 유형 글자가 항상 붙어 있다.
  - 매트릭스 점은 사분면 위치 자체가 유형이고, 툴팁·`aria-label`에 유형 이름이 있다. 점의 `aria-label`이나 `<title>`에 모양 단어(`마름모` 등)가 있으면 지운다. 자원 감소 신호는 `MCUI 60 (LC + 자원 감소)`처럼 글자로 남긴다.
- 원 둘레에는 어두운 바탕에서 보이는 얇은 테두리를 둔다(지금 원 점과 같은 방식). 유형 색끼리 맞닿아도 점이 구분되게 하기 위해서다.

## 절대 바꾸지 않을 것

- 유형 판정, 기준값 50, BBVI·MCUI·MFPI·MBPI 값, 자원 감소 신호 규칙과 점수(`config/`, `scripts/`, `dist/*.json`). 데이터에 모양 필드가 있으면 **그대로 둔다.** 화면에서 쓰지 않을 뿐이다.
- 네 유형 색, 유형 이름, 사분면 이름 글자, 배지 글자
- 점의 위치 계산, 밀집 구간 묶음·펼치기, 겹침 회피, 선택·점선 링 표시, 가중치 슬라이더 동작
- 위 '할 것'에 적은 세 문장(비교 탭 '읽는 법' 한 줄, 근거와 방법 한 줄) 말고는 문구 한 글자도 바꾸지 않는다
- 첫 화면, `expedition.html`, 멍이, 분류군 아이콘(`.group-icon`)
