# '근거와 방법' 탭 검증 성적표·05 항목 삭제 — Claude Code 작업 지침

## 할 것

'근거와 방법' 탭 맨 위의 **검증 성적표 패널을 통째로 지운다.** 다음이 모두 대상이다.

- `VALIDATION SCORECARD` 눈썹 글과 '검증 성적표' 제목
- 오른쪽 위 칩 세 개(식량 MFPI · 생리활성 MBPI · 보전 MCUI)
- 요약 줄('verified-4.19 기준 · 사후 검증 8건 중 …')과 결과 개수 줄(통과 · 기준 미충족 · …)
- 사후 검증 표 전체(머리줄, 모든 행, caption)

지우는 방법은 다음과 같다.

- `index.html`의 패널 마크업과 `app.js`에서 이 패널을 그리는 함수, 그 함수를 부르는 곳을 지운다. CSS로 숨기기만 하지 않는다.
- 이 패널에만 쓰던 CSS 규칙도 지운다.
- 바로 아래 'MCUI SCALE'(MCUI 범주 대응표)는 남긴다. 패널이 빠진 자리의 여백만 맞춘다.

## '05 신청서 약속은 어디까지 왔나요?' 항목 삭제

'근거와 방법' 탭의 접이식 항목 **'05 신청서 약속은 어디까지 왔나요?'를 통째로 지운다.**

- 대상: 항목 제목과 부제('신청서 약속 대비 구현 현황표 · 14개 항목'), 안내 문장, 상태 설명 줄(구현 · 부분 · 미구현 · 변경), 구현 현황표 전체
- 마크업, 이 표를 그리는 `app.js` 코드, 이 항목에만 쓰던 CSS를 함께 지운다. 숨기기만 하지 않는다.
- 01~04 항목의 번호와 문구는 그대로 둔다.
- 저장소에서 `신청서 약속`, `구현 현황`, 이 항목의 id로 검색한다. 05를 가리키는 링크나 문구가 다른 곳에 있으면 목록으로 만들어 PR에 적고, 링크는 지운다.

## 같이 고칠 것

성적표를 가리키는 문구가 남지 않게 한다. 저장소에서 `검증 성적표`와 `scorecard`로 검색한다.

- 03 '규칙 고정과 검증'의 MCUI 줄: `(대응표는 이 탭 위쪽, 검증 성적표 바로 아래)` → `(대응표는 이 탭 맨 위)`. 성적표가 빠지면 MCUI 대응표가 탭의 맨 위 블록이 된다.
- 성적표로 이동하는 링크나 클릭 동작이 있으면 `#method-03`으로 바꾼다

그 밖의 문구는 바꾸지 않는다.
