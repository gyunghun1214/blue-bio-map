# 휴대폰 '지도 크게 보기' (2026-10-25, LKH 요청)

LKH: "이 모바일 화면에서 중앙에 있는 하얀색 바 부분을 잡고 아래로 당기면 지도 전체 화면이 나오도록 UI 기능을 보완했으면 좋겠어."

## 바꾼 것 (휴대폰 폭 740px 이하만)

- 탐색 지도 아래 시트의 손잡이(가운데 흰 바) 또는 선택 종 요약을 **아래로 끌면** 시트가 내려가 손잡이와 종 이름 줄만 탭바 위에
  남고 지도가 그 자리까지 커진다(390×844에서 지도 422 → 692px). **위로 끌면** 원래대로(지도 화면의 50%).
- 끄는 동안 지도 아래 끝이 손가락을 따라오고, 놓으면 48px(`MAP_FULL_SNAP`)을 넘겨 끌었는지로 한쪽에 맞춘다(0.25초, '움직임 줄이기'면 바로).
- 지도는 위치·확대를 그대로 두고 보이는 범위만 아래로 넓힌다(Leaflet `invalidateSize({pan:false})`).
- 시트를 위로 쓸어 올리는 손가락은 전처럼 페이지 스크롤(관성 그대로). 아래로 끄는 손가락만, 그것도 페이지가 맨 위일 때만 이 기능이
  받는다(그 자리에서 브라우저 '당겨서 새로고침'이 뜨던 것도 막힌다).
- 끌기 대신 쓰는 방법:
  - 지도 오른쪽 아래, 확대/축소 바로 위 **'지도 크게 보기' 단추**(40px, `aria-pressed`, 아이콘이 '넓히기 ↔ 줄이기'로 바뀜)
  - 크게 본 상태에서 **손잡이 누르기** → 원래대로
  - 손잡이에서 **↓ 키**(펼친 시트 접기 → 지도 크게), **↑ 키**(거꾸로). `aria-keyshortcuts="ArrowDown ArrowUp"`
  - 손잡이 이름(aria-label)이 상태를 따라간다: 펼치기 / 접고 지도 보기 / **다시 올리기**(새 글자, 영어 사전 추가)
- 크게 본 동안 '근거 자세히 보기' 글자는 멍이와 겹쳐 숨긴다. 종 이름 줄을 누르면 전처럼 상세 시트가 열린다.
- 크게 본 상태는 공유 링크·주소에 남지 않는다. 740px을 넘으면(가로 돌리기 등) 원래대로 돌아간다.

그대로 둔 것: 점수·숫자·자료, 넓은 화면(741px~)의 화면과 동작, 멍이 끌기·위치, 하단 탭바, 지도 끌기·핀치.
새 화면 글자 두 개('지도 크게 보기', '종 목록·상세 다시 올리기')는 `scripts/i18n_ui_dict.py add`로 영어 사전에 넣었다(둘 다 aria-label).

## 확인

- `drag.mjs`(이 폴더): Chromium 휴대폰 흉내(터치, 2배) 360×780·390×844·430×932·영어 390에서 CDP 손가락 끌기로
  손잡이 아래로/위로, 짧게 끌면 그대로, 요약 줄 끌기, 단추 두 번, 손잡이 누르기, ↓·↑, 위로 쓸면 페이지 스크롤, 요약 누르면 상세 시트,
  가로 넘침 없음, 페이지 오류 없음 → 4폭 모두 통과. 크게 본 화면 캡처는 `full-*.png`.
- `verification/uicheck.mjs`에 'Mobile map full' 검사 추가(마우스로 끌기·단추·손잡이 누르기·↓↑).
- PC(1440×900·1280×720) 탐색·비교·표·방법 화면: main과 픽셀 비교(`../2026-10-25-mobile-ux/pc-diff.mjs`, 보통 움직임·움직임 줄이기, 두 번씩) → 고정된 차이 0(32장 × 2라운드).
- 확인 못 한 것: 실제 휴대폰(iOS Safari·삼성 인터넷·카카오톡 안 브라우저), 화면 낭독기. 터치 흉내는 Android Chrome(같은 엔진)뿐이다.
