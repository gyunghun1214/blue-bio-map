## 작업: 종 선택 시 첫 지도 표시를 '버블'로 통일

### 현상
'출현 기록' 탭에서 종을 선택하면 대부분은 처음에 해역별 붉은 버블(공개 셀 묶음)이 뜨고,
확대하면 셀별 붉은 점(도트)으로 바뀐다. 그런데 아래 6종은 선택 직후부터 버블 없이 도트가 나온다.
- 참문어, 참조기, 가리맛조개, 시카메굴, 큰가리비, 가시파레

예: 참문어는 '공개 셀 2개 · 기록 7건'인데, 제주와 규슈 북부 셀이 바로 점선 셀 + 붉은 점으로 표시됨.

사이트: https://blue-bio-map.blue-bio-map.workers.dev/

### 목표
모든 종이 선택 직후(첫 화면)에는 버블부터 보이고, 사용자가 확대해야 도트로 바뀌게 통일한다.
기존 버블↔도트 전환 규칙(줌 임계값)은 바꾸지 말 것.

### 먼저 원인 확인 (코드 수정 전에 결과를 보고해 줘)
1. 버블↔도트 전환 줌 임계값이 어디서 정해지는지 (상수 이름·값).
2. 종 선택 시 지도를 맞추는 코드(fitBounds / flyToBounds / setView)와 그때의 maxZoom·padding.
   → 6종 각각에 대해 선택 직후 실제 줌 값과 임계값을 비교해 로그로 확인.
   셀이 적거나 좁은 범위에 몰린 종이 임계값보다 더 확대되는 것이 유력한 원인.
3. 버블을 그리는 최소 조건이 있는지 (예: 묶음 안 셀 수 ≥ 2, 기록 수 하한, 셀 1개면 점으로 대체 등).
   → 참문어처럼 해역별 묶음이 셀 1개씩인 경우 버블이 생략되는지 확인.
4. 4° 민감종 셀, 기간(기간별 보기) 선택, 링크 복사로 줌이 들어오는 경우가 이 6종에 영향을 주는지.

### 수정 방향
- 종 선택 시 초기 맞춤의 maxZoom을 '버블 임계 줌 − 1'(버블이 보이는 가장 큰 줌)로 제한한다.
  범위가 작은 종도 버블이 보이는 줌에서 멈추게 하고, 필요하면 중심만 맞춘다.
- 버블 최소 조건 때문에 생략되는 경우, 셀 1개짜리 묶음도 버블(숫자 1)로 그린다.
- 공유 링크에 줌이 명시돼 들어온 경우에는 그 줌을 그대로 존중한다(초기 자동 맞춤에만 적용).
- 종별 예외 처리(종 이름 하드코딩)는 하지 말고, 모든 종에 같은 규칙이 적용되게 할 것.

### 검증
- 위 6종 + 기존에 정상이던 종 3개 이상(예: 셀이 많은 어류 1종, 해조류 1종, 4° 민감종 1종)을
  하나씩 선택해 첫 화면이 버블인지 확인.
- 확대하면 기존과 같은 줌에서 도트로 바뀌는지 확인.
- '전체 보기' 버튼, 기간 전환, 링크 복사 → 열기 흐름이 깨지지 않는지 확인.
- 모바일 폭(약 380px)에서도 첫 화면이 버블인지 확인.
- 변경 파일과 바뀐 상수/조건을 짧게 요약해 줘.
