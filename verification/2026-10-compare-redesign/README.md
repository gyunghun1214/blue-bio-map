## 시안과 일부러 다르게 둔 것

- **종 사진**: 이용 조건이 확인된 사진이 없어 분류군 아이콘과 '종 사진 없음 · ○○ 아이콘'을 쓴다. 사진과 이용 조건이 정해지면 `.cp-figure`에 넣으면 된다.
- **점 모양 범례**: 시안의 범례 대신 실제 규칙(근거 논문 2편 이상 = 속 찬 점, BBVI 근거 논문 1편 = 속 빈 점, 선택한 종 = 링). MBPI 하한값 점은 지금 자료에 없어 범례에서 뺐다(생기면 자동으로 나온다).
- **숫자**: 시안 숫자 대신 실제 값(참굴 BBVI 83.9·MFPI 71.6·MBPI 96.3·MCUI 10.0 한국 국가 평가). MCUI 10에 17종이 몰려 있어 점이 시안보다 아래에 모인다.
- **데이터 표**: 표는 밝은 카드로 남겼다. 근거 수준 칸(coverage)의 색 조합이 밝은 바탕에 맞춰져 있고, 표 검사(고정 열·머리글·스크롤)를 그대로 지키기 위해서다.
- **하단 '선택한 생물'**: 데스크톱은 시안처럼 패널 아래 한 줄. 740px 이하에서는 화면 아래 고정 막대로 접고 오른쪽 72px을 비워 멍이와 겹치지 않게 했다.
